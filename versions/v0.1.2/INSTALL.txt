拾词 LexiSide — 安装与使用说明

适用范围
本包是桌面版 Chrome 扩展，要求 Chrome 142 或更新版本。
请在电脑上安装；手机浏览器和小红书 App 内置浏览器不适用。
使用生产包无需安装 Node.js、Companion 或其他本机服务。

安装
1. 将 ZIP 解压到固定目录，保留全部文件。
2. 在 Chrome 地址栏输入 chrome://extensions，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 在普通英文网页上双击单词或选择文本，或点击扩展图标打开拾词侧栏。
Chrome 内部页面等受限页面无法使用网页划词功能。
本包采用手动安装方式；更新也需手动操作。

功能与费用
Chrome 本地翻译可用时，文本在本机翻译；首次使用需要联网下载语言包。
本地翻译不可用且未配置 DeepSeek Key 时，翻译可能无法完成；本机词库仍可使用。
学习分析与本地翻译失败后的回退翻译使用 DeepSeek 官方 API。
请在“设置 → 翻译与 AI → DeepSeek Key 与连接”填入你自己的 API Key。
创建 Key：https://platform.deepseek.com/api_keys
连接检查只验证 Key 与模型访问权限；实际使用可能需要账户有可用余额。
本包不附赠 API Key、余额或无限调用额度；费用以对应服务商的计费规则为准。

默认使用系统语音。豆包 AI 朗读为可选功能，需要你自己的火山引擎语音 API Key，
并开通语音合成 2.0 字符版。缓存未命中的试听与朗读可能产生费用。
豆包语音为 AI 合成；系统语音中标注“联网”的声线也可能通过网络处理文本。

权限与隐私
扩展需要在 HTTP/HTTPS 网页运行内容脚本，以支持划词与双击。
可在设置中关闭指定网站上的拾词交互。
学习分析会将当前原句发给 DeepSeek；开启相应选项后还会发送前后句、标题和来源域名。
本地翻译不可用时，选中的英文文本会在已配置 Key 的情况下发给 DeepSeek 翻译。
豆包朗读缓存未命中时，会将待朗读文本发给火山引擎语音服务。
请避免在包含敏感内容的页面使用联网翻译、分析或朗读。
Key 保存在浏览器本机扩展存储中，不是操作系统加密钥匙串；不包含在词库或目录备份中。
完整的数据处理、缓存保留、备份和删除说明见本包的 PRIVACY.md。

更新、备份与卸载
更新前先导出词库 JSON，或确认本机目录备份已成功。
将新版全部文件解压覆盖原目录，再到 chrome://extensions 点击重新加载。
不要随意更换加载目录或先卸载旧版，以免扩展 ID 变化或本机数据被删除。
卸载会删除扩展自己的词库、历史、设置、Key 和音频缓存。
你授权目录中的备份不会随卸载删除；备份含私人学习内容，请自行保管。
